# Presentation walkthrough

1. Extract the complete ZIP, then double-click **index.html**. No installation, API key or server is needed for the budgeting presentation.
2. On the sign-in screen, click **Use demo credentials**, then **Sign in**.
3. The pre-created user is **Jordan Demo** (`demo@budgetron.local` / `BudgetronDemo3000!`). These are dummy classroom credentials.
4. If the demo has been edited or the month has changed, use **Reset profile** and confirm to restore current-month sample records.
5. Home starts with **$3,000 income**, **$1,490 expenses**, and **$1,510 remaining**. Click **View Goals** to show the same $1,510 toward the $5,000 emergency goal.
6. Open Income to show the campus paycheck and freelance income. Create a category or add income, then show goal progress increasing.
7. Open Expenses to add a recorded expense; show remaining income and goal progress decreasing. Add a planned expense to demonstrate that it does not affect totals.
8. Open Pie Chart to show **separate income and expense graphs**, then click categories/slices for their details.
9. Open Transactions for the complete history and income/expense/planned filters. Edit or delete a record if desired.
10. Sign out. Create a separate test user to show an empty budget, then sign back into Jordan Demo to demonstrate data isolation.

Optional AI demo: run **Start Budgetron.bat** with Node.js 22+ installed, keep its window open and use the local website it opens. Add your private Gemini key to `.env` before presenting. Browser-only and server accounts/data are separate; use the pre-created Jordan Demo in either mode. An obvious off-topic request is handled locally; a budget question requires provider quota. Do not put the key into the login form, chat, GitHub, or presentation slides.
